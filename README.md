# 炉石一键修复 / HearthstoneFix

> 用炉石传说盒子玩游戏时频繁“拔线”，偶发闪退；闪退之后盒子启动游戏没反应，手动开炉石又一直提示“正在游戏中”，进不去。本项目就是为了解决这个问题：**闪退之后一键清理残留、自动拉起战网和炉石、再打开盒子，快速回到对局**。
>
> 全程不需要手动点战网的「进入游戏」按钮，跑完命令行窗口自动关闭。

- 适用系统：Windows 10 / 11（PowerShell 5.1 及以上）
- 已验证环境：国服战网 + 炉石传说 + 炉石传说盒子 + Windows 10 中文系统

---

## 一、项目背景与开发原因

### 1. 遇到的问题

在使用炉石传说盒子的过程中，对局里频繁“拔线”，之后偶发游戏直接闪退。闪退恢复时会卡住下面这条死循环：

1. **用炉石传说盒子再启动游戏，没有任何反应**；
2. **手动启动炉石传说，战网一直提示“正在游戏中”**，认为游戏还在运行，拒绝拉起新实例；
3. 去战网里执行扫描修复，扫描完提示“没有错误”，问题依旧；
4. 手动结束任务、重启战网等常规办法都不一定有效，这个状态会困扰很久，只能反复折腾甚至重启电脑。

### 2. 根因分析

排查后确认通常有三类原因：

| 根因 | 表现 | 为什么常规办法无效 |
| --- | --- | --- |
| **炉石进程内核级卡死（僵尸残留）** | 进程只剩几十 KB 内存、没有窗口、取不到命令行路径 | 普通 `Stop-Process`、`taskkill /F`，甚至提权后结束，全部返回 `Access denied`。它留在系统里，战网就永远判定“游戏正在运行”。这种进程只能靠重启电脑清除。 |
| **战网后台服务 / Agent 状态异常** | 战网界面能开，但拉起游戏的后台链路不工作 | 需要重启 `battlenet_helpersvc` 服务并让 Agent 重新就绪。 |
| **Windows 游戏叠加层与盒子覆盖层冲突** | 叠加层（GameDVR / Game Bar）和盒子覆盖层互相干扰，诱发闪退 | 关闭 GameDVR 相关项，降低再次闪退的概率。 |

### 3. 项目目的

- **核心目标**：闪退后双击一次脚本，自动完成清理和拉起，最快速度回到游戏，不需要逐项手动排查。
- **做完的事**：清理卡死残留 → 修服务 → 自动启动战网 → 自动识别并点击「进入游戏」→ 校验游戏真的起来了（防止“闪一下就退出”被误判成功）→ 启动炉石盒子 → 自动关窗。
- **不做的事**：不修改游戏文件、不绕过战网授权或反作弊、不碰卡组/收藏/账号数据。

## 二、实现步骤（脚本执行流程）

主脚本 `HearthstoneFix.ps1` 按下面顺序执行，每一步都写进同目录运行日志 `hs-fix-log.txt`（每次运行覆盖）。

### 第 1 步：结束残留进程

结束 `Hearthstone` / `Hearthstone_x64`、`Battle.net`、`Battle.net Helper`、`Agent`、`BlizzardBrowser`、`BlizzardError`，以及盒子 `HSAng`（`-KeepBox` 可保留盒子）。

### 第 2 步：僵尸进程检测与重启确认

- 判定规则：炉石进程内存 **小于 20MB** 且 **没有窗口**，即判定为内核卡死残留。
- 先尝试普通结束；结束不掉的，再用 **SYSTEM 身份**（一次性计划任务执行 `taskkill /F /T`）强杀一次——这是不重启电脑的最后一次机会，能清掉就继续自动启动，不用重启。
- SYSTEM 也清不掉时，阻断后续启动，并提示：
  > 按 [空格] 或 [回车] 确认并重启；按其他键取消（只退出，不重启）
- 确认后进入 8 秒倒计时：倒计时过程中**每按一次空格或回车，剩余时间立即减少 1 秒**（可连按累积加速，例如连按 5 次就立刻结束倒计时），按其它键则取消。随后优先 `shutdown.exe /r /t 0 /f` 重启，失败再回退 `Restart-Computer -Force`。重启后重新双击一次脚本即可全自动。
- 取消返回退出码 `2`；重启失败返回 `3`。

### 第 3 步：关闭游戏叠加层

把以下注册表项置 0（`-RestoreOverlay` 可改回开启）：

- `HKCU:\System\GameConfigStore\GameDVR_Enabled`
- `HKCU:\Software\Microsoft\Windows\CurrentVersion\GameDVR\AppCaptureEnabled`
- `HKCU:\Software\Microsoft\GameBar\ShowStartupPanel`
- `HKCU:\Software\Microsoft\GameBar\UseNexusForGameBarEnabled`

### 第 4 步：清理旧日志

- 默认保留 3 天，删除超期的 `Hearthstone_*` 会话目录；
- 当前会话目录里的 `Power.log` 超过 50MB 时清空（不删文件，只截内容）；
- `-SkipLogs` 可跳过这一步。

### 第 5 步：重启战网后台服务

- 重启 `battlenet_helpersvc`（需要管理员权限；非管理员运行时这步跳过，其余照常）；
- `-ResetAgent` 可额外把 `C:\ProgramData\Battle.net\Agent\Agent.dat` 备份后重置。

### 第 6 步：启动战网并自动点击「进入游戏」

1. 拉起战网，等待主窗口出现（最长 120 秒），再等待后台 Agent 就绪（最长 90 秒）；
2. **先把本脚本自己所在的命令行窗口最小化**，避免 cmd 挡住战网按钮；
3. 战网窗口最大化、切到最前，全屏截图；
4. 用下面“技术实现”里的三重方式定位按钮并模拟鼠标点击；
5. 轮询游戏进程，确认被拉起。

点击失败时，依次回退：`--uid=WTCG` → `battlenet://WTCG` → `--uid=hs_beta` → `battlenet://hs_beta` → 炉石独立启动器 `Hearthstone Beta Launcher.exe` → 直接启动 `Hearthstone.exe`（直启可能被战网判为未授权而闪退，所以放在最后）。

### 第 7 步：校验游戏真的起来了

- 等待游戏窗口（最多 `LaunchTimeout` 秒，默认 120）；
- 窗口出现后**再盯 6 秒**，确认没有“闪一下就退出”；若已退出，打印最近 12 行游戏日志和崩溃事件，返回失败。

### 第 8 步：启动炉石盒子并结束

- 等待 3 秒后启动 `HSAng.exe`，校验盒子进程出现；
- 按返回码分流：`0` 成功、`2` 已取消 → 3 秒后自动关窗；`1` 失败、`3` 重启失败 → 保留窗口方便看报错。

## 三、使用方法

### 快速开始

1. 把整个 `HearthstoneFix-main` 文件夹放到任意位置（从 GitHub 下载 zip 解压即可，**不要只拷贝 bat 一个文件**）；
2. 双击 `一键修复.bat`。**会自动弹出 UAC 请求管理员权限，点「是」**——脚本需要管理员才能重启战网后台服务、用 SYSTEM 身份强杀卡死进程。同时第一次运行会在桌面创建带炉石图标的「炉石一键修复」快捷方式，以后直接点桌面图标即可（同样会弹 UAC）；
3. 完成后窗口自动关闭；出问题时看同目录 `hs-fix-log.txt`。

第一次在新电脑上运行，脚本会自动探测战网、炉石、盒子的安装位置，一般不需要改任何配置。若日志里出现某一项“未找到”，在 `config.ini` 里填上真实路径即可。

> UAC 里点了「否」不会报错退出，脚本会降级为**普通权限继续跑**（日志里显示 `管理员: 无`），只是“重启战网服务”“SYSTEM 强杀僵尸进程”这两步会跳过。

> 如果双击 bat 只闪过一句 `'l' is not recognized as an internal or external command`，说明 bat 的换行格式被破坏了（Windows 的 cmd 需要 CRLF）。本项目仓库里的 bat 已经是 CRLF + GBK，正常下载解压不会出这个问题；用记事本另存、或用某些工具转码会破坏它，重新解压一份即可。脚本本身也已改成不依赖括号块的写法，即便换行被改坏也能跑起来。

### 命令行参数

```
一键修复.bat                 完整流程
一键修复.bat -DryRun         只看会做什么，不真的改
一键修复.bat -NoLaunch       只修复，不启动游戏
一键修复.bat -KeepBox        不结束盒子进程
一键修复.bat -Retry          启动失败时自动再修一次
一键修复.bat -LaunchTimeout 180   等待游戏窗口的秒数（默认 120）
一键修复.bat -SkipLogs       不清理日志
一键修复.bat -SkipOverlay    不改游戏叠加层设置
一键修复.bat -RestoreOverlay 把叠加层设置改回开启
一键修复.bat -ResetAgent     额外备份重置战网 Agent 状态库（Agent.dat）
一键修复.bat -TestClick      只测试按钮识别与点击
一键修复.bat -TestReboot     只测试“按键确认后重启”的交互
一键修复.bat -TestReboot -SimKeys ss  自动化测试倒计时：s=空格、e=回车、x=其它键（仅配合 -TestReboot）
一键修复.bat -KeepConsole    点击时不最小化命令行窗口（调试用）
一键修复.bat -NoShortcut     跳过“首次运行自动创建桌面快捷方式”
```

> 所有参数都会被带到提权后的进程里，例如 `一键修复.bat -DryRun` 依然只预览。

### 返回码

| 返回码 | 含义 | 窗口行为 |
| --- | --- | --- |
| `0` | 成功 | 3 秒后自动关闭 |
| `2` | 用户取消重启 | 3 秒后自动关闭 |
| `1` | 启动失败 | 保留窗口，看报错 |
| `3` | 自动重启失败 | 保留窗口，看报错 |

## 四、注意事项

### 运行环境

- **仅支持 Windows**（10 / 11），依赖战网客户端、PowerShell 5.1+；不支持 macOS / Linux。
- 建议**以管理员身份运行**：双击 bat 或桌面快捷方式时会自动弹 UAC，点「是」即可（重启战网服务、SYSTEM 强杀需要管理员）；点「否」则以普通权限继续，这两步跳过。
- bat 入口已带 `-ExecutionPolicy Bypass`，不需要手动改本机 PowerShell 执行策略。

### 运行前状态

- 战网需要**已经登录**，并且界面停在**炉石详情页**。如果停在登录页或别的游戏页面，识别不到启动按钮，脚本会在日志里列出它看到的文字，再走兜底方式。
- 脚本只做本机进程、服务和启动层面的操作；游戏能否进入最终仍取决于战网授权是否正常。

### 数据安全

- 不会动卡组、收藏、账号数据；只结束进程、改叠加层开关、清理超期日志和超大日志文件。
- `-ResetAgent` 会先备份 `Agent.dat`（带时间戳的 `.bak` 文件），不会直接删除。

### 编码与文件约束

- `一键修复.bat` 必须保持 **CRLF 换行 + GBK(936) 编码**，否则 cmd 会把命令拆碎，报 `'~dp0"' is not recognized...`。改 bat 时请用支持指定编码的编辑器另存。
- `HearthstoneFix.ps1` 为 UTF-8 带 BOM。
- `hs-fix-log.txt` 是运行日志，已在 `.gitignore` 中忽略，不会进入版本库。

### 跨电脑的边界

- 路径探测覆盖不到的极端情况：安装目录超过 4 层（例如 `D:\Games\网易\暴雪\Battle.net\Battle.net.exe`），同时没有快捷方式、程序没在运行、注册表和战网配置都没记录。这时日志会打印“未找到”，在 `config.ini` 填一行路径即可，不用改代码。
- OCR 依赖系统中文识别语言包；缺失时会自动回退到色块 / 颜色识别，不影响主流程。

## 五、技术实现说明

### 5.1 自动点击：三重识别，不写死坐标

脚本**不保存任何屏幕坐标**，每次运行都在战网窗口画面里重新定位按钮，依次尝试：

| 优先级 | 方式 | 说明 |
| --- | --- | --- |
| 1 | **文字识别（OCR）** | 用 Windows 自带识别引擎（`Windows.Media.Ocr`），在战网窗口画面里找「进入游戏 / 开始游戏 / 进行游戏 / 启动游戏 / 开始对局 / 进入对局 / Play」等字样，命中就点该行文字中心。分辨率、DPI 缩放、窗口大小、主题变化都不影响。 |
| 2 | **自适应色块** | 在窗口下半部分找“大面积高亮条状区域”，用饱和度/亮度判断，不写死颜色阈值，按钮换成红/绿/紫也能认。 |
| 3 | **颜色兜底** | 战网经典蓝色按钮判据，作为最后一道保险。 |

### 5.2 路径自动探测链

脚本里**没有写死任何安装路径**，三款软件各自按优先级探测，命中即用：

| 优先级 | 战网 `Battle.net.exe` | 炉石 `Hearthstone.exe` | 盒子 `HSAng.exe` |
| --- | --- | --- | --- |
| 1 | `config.ini` 手填 | `config.ini` 手填 | `config.ini` 手填 |
| 2 | 战网 `%APPDATA%\Battle.net\Battle.net.config` 里的 `"Path"` 字段 | 卸载注册表项 `InstallLocation` / `DisplayIcon` | 卸载注册表项 |
| 3 | 正在运行的 `Battle.net` 进程真实路径 | 正在运行的 `Hearthstone` 进程路径；**战网目录内的 `Hearthstone\Hearthstone.exe`（战网内置安装，如 `I:\Battle.net\Hearthstone\`）** | 正在运行的 `HSAng` 进程路径 |
| 4 | 开始菜单 / 桌面快捷方式 | 快捷方式（国服多指向 `Hearthstone Beta Launcher.exe`，自动取同目录主程序） | 快捷方式（自动排除 Uninstall 项） |
| 5 | 卸载注册表项 / Blizzard `InstallPath` | 各盘常见目录 | 各盘常见目录 |
| 6 | 各盘常见目录 | 浅层全盘搜索（深度 4，限时 30 秒） | 浅层全盘搜索（限时 20 秒） |
| 7 | 浅层全盘搜索（深度 4，限时 30 秒） | — | — |

### 5.3 进程状态判定

- **真在运行**：内存 ≥ 20MB，或存在主窗口句柄；
- **卡死残留**：内存 < 20MB 且无主窗口句柄；
- 判定时对僵尸进程的属性访问做了容错（这类进程读 `WorkingSet64` / `MainWindowHandle` 会抛错）。

```
HearthstoneFix-main/                 # GitHub 下载 zip 解压后的目录名，可随意放
├── 一键修复.bat                    # 入口：调用 PowerShell，按返回码决定是否关窗（CRLF + GBK，勿用记事本另存）
├── HearthstoneFix.ps1              # 主脚本（UTF-8 带 BOM）
├── config.ini                      # 可选路径覆盖，默认全部注释
├── README.md                       # 本说明文档
├── .gitignore                      # 忽略运行日志
├── hs-fix-log.txt                  # 运行日志（每次运行覆盖，不入库）
└── icon/
    └── HearthstoneFix.ico          # 桌面快捷方式图标
```

### `config.ini` 可选填法

```ini
BattleNetExe=D:\Battle.net\Battle.net.exe
```

`GameUid` / `GameUidAlt` 只有点击失败后走兜底时才用到，国服保持默认即可。

## 七、常见问题

**Q：点击了但游戏没起来？**
看 `hs-fix-log.txt` 里 `[识别]` 那几行。如果显示“未见启动字样”并列出识别到的文字，说明战网不在炉石详情页（可能停在登录页或别的游戏），先手动进到炉石页面再运行。

**Q：提示发现卡死残留、要求重启？**
这是内核级僵尸进程：普通结束、提权 `taskkill /F` 全部 `Access denied`，进程已经进入内核的“等待终止”状态。脚本会先用 SYSTEM 身份的一次性计划任务强杀一次，成功就免重启继续；仍然清不掉时才要求重启。重启提示按空格或回车确认，倒计时中再按空格/回车还能每次提前 1 秒（连按就越快），按其它键只退出、不重启。

**Q：需要管理员权限吗？**
需要。bat 会在启动时用 `Start-Process -Verb RunAs` 自动重新拉起自己，弹出 UAC 后点「是」即可；提权后的窗口会接着跑完整流程（会保留原命令行参数）。如果点了「否」，脚本不会退出，而是降级为普通权限继续，仅跳过“重启战网服务”和“SYSTEM 强杀”两步。

**Q：脚本会改我的游戏数据吗？**
不会。只结束进程、改叠加层开关、清理超期日志（默认保留 3 天）和超过 50MB 的 `Power.log`，不碰卡组、收藏和账号数据。

**Q：OCR 识别不出来怎么办？**
会自动回退到色块和颜色识别。如果三种方式都失败，日志会记录识别到的界面文字，据此判断战网当前停在哪个页面。
